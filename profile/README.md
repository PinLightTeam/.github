## 💡 Зачем это всё

Сейчас жизнь вокруг разбросана по разным приложениям. Событие ищешь в одном сервисе, место сохраняешь в другом, обсуждаешь в мессенджере, а фото отправляешь куда-то ещё. По дороге половина теряется.

**PinLight собирает всё в одном месте.** Заметил что-то интересное — поставь метку. Её сразу увидят все, кто рядом. Под ней можно поспорить в комментариях, написать автору в личку, построить к ней маршрут или отправить другу красивой картинкой. Переключаться между приложениями не нужно.

> Карта перестаёт быть справочником. Она становится лентой того, что происходит вокруг.

---

## 📍 Метка — главный герой

Метка в PinLight — это не просто точка. Это маленькая история с категорией, текстом, фотографиями и **сроком жизни**.

- ⏳ **Метки живут недолго.** Уличный концерт закончился, очередь рассосалась, закат отгорел — и метка тает. Вокруг неё видно кольцо, которое показывает, сколько ей осталось.
- ⚡ **Появляются у всех мгновенно.** Через WebSocket, без обновления страницы.
- 👆 **Ставятся двойным касанием.** Тапнул по карте — выбрал категорию — готово.
- 💬 **Обсуждаются на месте.** Комментарии, лайки и переход в профиль автора.
- 🖼️ **Делятся картинкой.** Кусочек карты с меткой рендерится на лету и отправляется куда угодно.
- 🧭 **Ведут за собой.** Маршрут до метки строится в одно касание.
- 🔥 **Складываются в тепловую карту.** Сразу видно, где сегодня жарко.

## 🗺️ Живая карта

Мы хотим, чтобы карта ощущалась как окно на улицу, а не как схема.

| | |
|---|---|
| 🌦️ **Погода** | Если на улице дождь или снег, то он идёт и на карте. Дороги блестят от сырости. |
| 🌙 **День и ночь** | Карта следит за солнцем. Вечером в городе зажигаются огни. |
| 🍂 **Времена года** | Палитра меняется вместе с сезоном. |
| 🏛️ **3D-достопримечательности** | Над картой стоят Исаакиевский собор, Пизанская башня, Колизей, Эйфелева башня и другие модели. |
| 🏙️ **Детализированный город** | 3D-здания, разметка, ступени, велодорожки, трамвайные пути, номера домов и края парков. |
| 📡 **Офлайн** | Карта кэшируется и работает даже без сети. |

### 🎲 «Удиви меня»

**Встряхни телефон**, и карта качнётся в ответ, а потом улетит через полглобуса к случайной метке где-то в мире. Это лучший способ узнать, чем сейчас живут люди в других городах.

### 👀 «Что рядом»

Панель со всеми метками в кадре, по которым можно быстро пролистать. Если несколько меток стоят друг на друге, они раскрываются веером.

---

## 🔒 Места — только для своих

Не всё должно быть публичным. В разделе **«Места»** собраны личные метки, которые видите только вы: любимая кофейня, парковка у дома, «сюда вернуться летом».

- 📂 Метки можно раскладывать по **группам**.
- 📴 Раздел работает **без интернета** и синхронизируется, когда сеть появляется.

---

## 💬 Общение без побегов в мессенджер

- Личные чаты в реальном времени.
- Сообщение появляется сразу после отправки, а повторная отправка не создаёт дублей.
- Статусы «отправляется → отправлено → прочитано» и счётчики непрочитанного.
- Push-уведомления, чтобы не пропустить ответ.

## 📱 Везде, где вы

| | |
|---|---|
| 🌐 **Веб** | PWA: можно установить на рабочий стол, работает офлайн |
| 🤖 **Android** | APK с автообновлением из GitHub Releases, отдельная сборка для RuStore |
| 🍏 **iOS** | Нативная сборка через Capacitor |

Одна кодовая база на Vue работает на всех платформах. На мобильных доступны нативные возможности: геолокация, вибрация, датчик движения, системный «Поделиться» и push-уведомления.

Тёмная и светлая темы 🌗 · русский и английский 🇷🇺 🇬🇧 · онбординг для новичков
