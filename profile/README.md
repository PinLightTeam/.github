## 🌍 О проекте

**PinLight** — социальная платформа вокруг интерактивной карты. Здесь можно отметить интересное место, рассказать о происходящем рядом, найти события поблизости и пообщаться с другими людьми — всё в реальном времени и в привязке к местности.

Идея простая: карта должна показывать не только улицы и здания, но и то, что происходит вокруг прямо сейчас.

> ⚠️ Проект находится в активной разработке и пока не анонсирован публично.

## ✨ Возможности

### Для пользователей

- 🗺️ **Метки на карте** — отмечайте места и делитесь ими с сообществом
- 📣 **События** — публикуйте и находите события рядом с собой
- 💬 **Чат** — общайтесь с другими участниками прямо в приложении
- 👤 **Профиль** — аватар, публичная информация и персональные настройки
- 📷 **Фотографии** — прикрепляйте снимки к меткам и событиям
- 🐞 **Обратная связь** — сообщайте об ошибках и предлагайте идеи из приложения

### Скоро

- 🔒 **Личные метки** — места, которые видите только вы, по аналогии с «Избранным» в картах
- 👨‍👩‍👧 **Группы «Семья»** — общие личные метки для близких и отдельный слой на карте
- 🏛️ **Достопримечательности** — 3D-модели на карте и знакомство с местом в формате коротких историй
- 🔔 **Push-уведомления** — чтобы не пропускать важное

## 📱 Платформы

| Платформа | Статус |
|---|---|
| 🌐 **Веб-приложение** | Доступно в браузере на десктопе и мобильных |
| 🤖 **Android** | Устанавливается как APK |

Оба клиента собираются из единой кодовой базы фронтенда, поэтому функциональность и интерфейс одинаковы на всех устройствах.

## 🧭 Как устроен PinLight

```
   ┌───────────────────────────────────────────┐
   │        Клиенты: Web  ·  Android (APK)      │
   │             Фронтенд на Vue                │
   └─────────────────────┬─────────────────────┘
                         │ HTTPS
   ┌─────────────────────▼─────────────────────┐
   │      API-шлюз (Traefik) + авторизация      │
   └─────────────────────┬─────────────────────┘
                         │
   ┌─────────────────────▼─────────────────────┐
   │        Микросервисы на Go                  │
   │  авторизация · профили · карта и метки ·   │
   │  события · чат · обратная связь · почта …  │
   └─────────────────────┬─────────────────────┘
                         │
   ┌─────────────────────▼─────────────────────┐
   │  Событийная шина (Kafka) · БД · хранилище  │
   │             файлов (S3)                    │
   └───────────────────────────────────────────┘
```

**Фронтенд** — единое Vue-приложение, которое работает в браузере и упаковывается в Android-приложение. Он отвечает за карту, ленту событий, чат, профиль и все пользовательские сценарии.

**Бэкенд** — набор независимых сервисов на Go, у каждого своя зона ответственности. Все запросы проходят через единую точку входа, где проверяется авторизация, а сервисы обмениваются событиями через Kafka — так данные на карте обновляются в реальном времени.

**Данные** — учётные записи и персональные данные изолированы в отдельном сервисе авторизации, а фото и файлы хранятся в собственном S3-хранилище.

## 🛠 Технологии

| Часть | Технологии |
|---|---|
| Фронтенд | Vue |
| Мобильный клиент | Android (APK) на базе веб-фронтенда |
| Бэкенд | Go, микросервисная архитектура |
| API-шлюз | Traefik |
| Обмен событиями | Apache Kafka |
| Хранение данных | PostgreSQL, Redis, S3-совместимое хранилище |
| Уведомления | Firebase Cloud Messaging |
| Мониторинг | Prometheus, Grafana |
| Инфраструктура | Docker |

## 🔗 Экосистема

- **TaskTracker** — собственный трекер задач команды, связанный с обратной связью пользователей: каждый баг-репорт можно привязать к задаче, которая его исправляет.
- **Админ-панель** *(в разработке)* — управление данными и мониторинг приложения в реальном времени.
